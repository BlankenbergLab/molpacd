# Test Data

## `2iww.pdb`

This fixture is derived from PDB entry `2IWW`, outer membrane protein G, and is
used to exercise realistic PDB parsing, aperture analysis, cap addition, and cap
removal paths.

Keep real structure fixtures small enough for normal CI runs. When adding new
fixtures, record the source database, accession, relevant citation or authors,
and any truncation or preprocessing performed before committing the file.
